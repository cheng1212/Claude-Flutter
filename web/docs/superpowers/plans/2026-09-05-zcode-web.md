### Task 3: WS 客户端(鉴权/心跳/重连/seq)

**Files:** Create `src/lib/socket.ts`; Test `src/lib/socket.test.ts`

移植 Flutter `ws.dart`,接口浏览器化:

```ts
export type SocketState = 'idle'|'connecting'|'open'|'reconnecting'|'closed';
export interface ZChannel { send(data: unknown): void; close(): void;
  onData(cb: (msg: Record<string, unknown>) => void): () => void; onClose(cb: () => void): () => void; }
export type ChannelFactory = (uri: string) => Promise<ZChannel>;
export class ZSocket {
  constructor(opts: { uri: string; token: string; factory?: ChannelFactory;
    backoffBaseMs?: number; maxBackoffMs?: number; pingEveryMs?: number })
  state: SocketState; failure?: string;
  onEvent(cb: (ev: Record<string, unknown>) => void): () => void;   // 全部服务端消息
  onStateChange(cb: () => void): () => void;
  connect(): Promise<void>;                     // 鉴权握手 8s 超时,失败抛错
  close(): void;                                // 不再重连
  subscribeSession(id: string): void;           // 已连接即发,否则等 resubscribe
  seedLastSeq(id: string, seq: number): void;   // 只前进
  sendChat(id: string, content: string, opts?: {model?:string; permissionMode?:string}): void;
  answerPermission(id: string, requestId: string, allow: boolean, message?: string): void;
  abort(id: string): void;
}
```

测试(fake channel + vi.useFakeTimers):auth 消息先发且带 token、非 authenticated 抛错、open 后重发订阅(带 lastSeq)、断线后指数退避重连且封顶、close 后不再重连、ping 定时发送、replay 事件与带 sessionId 事件推进 lastSeq。
- [ ] RED → GREEN → Commit `feat: websocket client with auth, ping, backoff, seq resume`
