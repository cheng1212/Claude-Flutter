## A. 测试角度拆分(全盘测试的八个维度)

| # | 维度 | 覆盖内容 | 主要手段 |
|---|---|---|---|
| A1 | **业务逻辑正确性** | 会话生命周期、seq/replay 协议、审批流、cron 触发与删除、用量聚合口径、权限模式语义 | 单测 + 三端对照 |
| A2 | **代码健壮性** | 网络失败、超时、并发竞态(代际令牌)、大会话、空态/异常态、服务重启恢复 | 故障注入 + 边界用例 |
| A3 | **安全** | 鉴权覆盖、路径穿越、注入、密钥管理、CORS | 静态扫描 + 用例 |
| A4 | **三端一致性** | app/web/server 协议对齐、功能对齐(差距清单见 B 表"差距"列)、术语与交互对齐 | 功能矩阵逐项比对 |
| A5 | **性能** | 首屏时间、大会话(千条级)、图片内存、列表滚动帧率 | 计时 + 长会话实测 |
| A6 | **兼容性** | 桌面 Chrome/Edge、手机浏览器(含 WebView)、窄屏、深色系统 | 手动矩阵 |
| A7 | **可用性/交互** | 导航完整性、加载反馈、错误可恢复性、空态引导 | 走查 + 用户反馈 |
| A8 | **工程卫生** | 测试覆盖增长、文档同步、依赖健康、分支/仓库卫生 | CI 化检查清单 |

当前基线(2026-09-14):app 210 / server 150 / web 103 测试全绿;三端 analyze/tsc/build 全过。
