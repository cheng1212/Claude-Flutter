## 四、正确性维度

### 4.1 今日修复的质量亮点（值得肯定）

1. **`fix-usage-clamp-crash`**：抓到“paint 每帧抛 clamp 异常 + 每帧写日志”拖死主线程（实测卡顿 12.9s），修越界之外还把 FlutterError 高频异常降频——连“日志自己成为卡顿源”都想到了。
2. **`feature-lazy-history`**：按需加载用 `beforeSeq` 锚点免疫新消息漂移、代际令牌防竞态，并且发现并修掉“server 倒序返回、倒序灌 reducer 会被 `seq ≤ lastSeq` 去重吞到只剩 1 条”的隐蔽坑（注释带实测数据）。
3. **`fix-stop-button-stuck` / `151b334`**：停止链路“interrupt 无回执堵死强裁”改为最多等 2s 必达，server+web 双端同修。
4. **`feature-cron-delete-real`**：查明 Claude Code 的 cron 是 session-only（只活在 CLI 内存），面板删除改为“删镜像 + 向 CLI 发 CronDelete 指令”，`cliNotified` 如实反馈——不撒谎的 UI。
5. **`800ab8a`（web）**：错 token 不再“假进主界面处处 401 卡死”——登录先探针、任意 401 自动登出。
